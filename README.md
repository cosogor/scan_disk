# scan_disk
Disk Surface Scanner Script (Python)
Скрипт-сканер поверхности диска (Python)


Реализовано на Python посекторное чтение физического диска (аналог режима Ignore / Scan), чтобы:
1. Находить медленные и нечитаемые (битые) сектора.
2. Посекторно вычитывать данные вокруг повреждённых участков и сохранять их в папку damages (по принципу утилиты ddrescue).
3. Формировать карту сбойных секторов (bad_sectors.txt), чтобы затем передать их список файловой системе (например, через fsck -l в Linux), которая сама «спрячет» эти блоки от использования.
Ниже приведён рабочий скрипт на Python, который выполняет сканирование диска, замеряет время отклика и сохраняет дампы сбойных участков в папку damages.



Важно: Скрипт работает только в режиме чтения (rb), поэтому он безопасен для данных. 
Для доступа к физическому диску его нужно запускать от имени Администратора (в Windows) или через sudo (в Linux).

Как это работает на практике и как изолировать битые сектора?
1. Что делает скрипт:
	• Читает диск большими блоками по 64 КБ (для высокой скорости).
	• Если блок читается дольше 200 мс (аналог оранжевых/красных квадратов в Victoria), скрипт сохраняет его содержимое в файл slow_sector_XXXX.bin в папке damages, пока участок окончательно не вышел из строя.
	• Если при чтении возникает физическая ошибка ввода-вывода (OSError), скрипт переключается на посекторное чтение по 512 байт, записывает номера битых секторов в bad_sectors_list.txt, а уцелевшие соседние сектора с нулями вместо битых сохраняет в damaged_block_sector_XXXX.bin.
2. Как запретить системе использовать эти сектора:
	• В Windows: после сканирования запустите chkdsk X: /b (для NTFS) — Windows сама перепроверит сбойные кластеры и занесёт их в системный файл $BadClus, чтобы больше никогда туда ничего не писать.
	• В Ubuntu (Linux): передайте созданный скриптом файл bad_sectors_list.txt в утилиту e2fsck:bash
sudo e2fsck -l damages/bad_sectors_list.txt /dev/sda3
 
Эта команда добавит найденные сектора в таблицу сбойных блоков файловой системы (badblocks inode), и Ubuntu перестанет их использовать.
